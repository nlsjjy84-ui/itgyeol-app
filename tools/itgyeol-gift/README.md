# itgyeol-gift — 잇결 서버 (사진 · 주문 · 전시 · 토스 테스트 결제)

키오스크에서 찍은 깜짝 선물 사진을 QR로 폰에 옮기고, 손님 폰·굿즈숍·업체 화면·박물관 큰 화면이 서로 다른 기기여도
같은 주문과 전시 신청을 보게 하는 아주 작은 서버입니다.

- **GET/POST/PATCH /api/orders** — 주문 목록, 모의·계산대 결제 주문 넣기, 업체 단계 넘기기·손님 취소. 금액은 서버가 가격표로 다시 계산합니다.
- **GET/POST /api/exhibit** — 전시 신청 목록, 신청·걸기·내리기(별명 10자·나라만, 이름 없음).
- **GET/POST /api/pay** — 토스페이먼츠 **테스트 키만**(test_ck_ / test_sk_). 앱이 보낸 금액이 서버 계산과 다르면 승인 요청을 하지 않습니다. 취소하면 토스에서도 결제 취소합니다.
- 주문·전시 기록은 7일, 사진은 24시간 뒤 지웁니다. 키는 Vercel 환경 변수에만 있습니다(앱·GitHub에 없음).
- **서버 고치기**: `deploy-connect.ps1`(저장소 맨 위 bat이 부름) — 로그인 확인 · 테스트 키(선택) · 배포 · 확인.

- **어디에**: Vercel Functions + Vercel Blob (이미 쓰는 Vercel 계정, 무료 범위)
- **POST /gift** (image/jpeg, 3MB 이하) → `{ url }` — 짐작할 수 없는 36자리 번호 주소. 앱이 이 주소를 QR로 보여 줍니다.
- **지우기**: 24시간 지난 사진은 새 사진이 올라올 때마다, 그리고 매일 한 번(cron) 지웁니다.
- **받는 곳 제한**: `https://nlsjjy84-ui.github.io`(잇결 웹 앱)에서만 올릴 수 있습니다(CORS).
- **설정**: 저장소 맨 위 `setup-gift.bat`을 한 번 실행 → 로그인 · 프로젝트 · 저장소 · 배포 · 앱에 주소 넣기까지 자동.
- **테스트**: `npm install && node test.mjs` (가짜 Blob으로 업로드·형식·크기·하루 지난 사진 지우기 확인)
